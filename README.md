# House Price Prediction

## Overview
A simple machine learning project built with Python and scikit-learn to predict house prices using regression analysis.

## Project Structure
- `train_model.py`: Python script containing code to load data, train the linear regression model, evaluate performance, and save the model.
- `house_price_model.pkl`: Saved trained model file.
- `report.txt`: Short report of findings and performance metrics.
